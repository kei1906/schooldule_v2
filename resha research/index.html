LSHS Research Framework (IPO Model)

DEVELOPMENT OF CENTRALIZED SCHOOL INFORMATION AND SCHEDULING WEBSITE FOR LAGUNA SENIOR HIGH SCHOOL STUDENTS

Category: Science Innovation | Lead Researchers: Durante, Advento, Amador, Belmes, Chingtoco, Concio, Namuag, Pasco

1. INPUT
  • Respondent Demographics
  • School Announcements Data
  • Class Section Schedules
  • Clubs & Info Directory
  • Supabase Cloud DB Credentials
2. PROCESS
  • Portal Framework Coding
  • Website Testing Phase (1 Mo.)
  • Data Gathering (Likert Scale)
  • Descriptive & Paired T-Test
  • Interface Optimization
3. OUTPUT
  • High User Accessibility
  • Ease of Information Retrieval
  • Reduced Social Media Overload
  • Higher Academic Planning Efficiency
